【GitHubへアップロードするもの】
このフォルダ内の以下を、リポジトリの同じ階層へすべてアップロードしてください。
- index.html
- styles.css
- app.js
- assets フォルダ

README.txt は説明用のため、GitHubへアップロードしてもしなくても動作に影響しません。

【現在の接続先】
事業部Googleアカウントで公開したGAS Webアプリ（TEST環境）に接続済みです。

【テスト表示】
GitHub Pagesの公開URL末尾に ?test=1 を付けて開いてください。
例：https://ユーザー名.github.io/リポジトリ名/?test=1

【重要】
抽選を行うと、TEST側の抽選履歴と在庫が実際に更新されます。
PRODUCTION側の在庫は、設定シートの環境がTESTの間は変更されません。
